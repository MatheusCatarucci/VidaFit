# 🇧🇷 Português

## 📌 Sobre o Projeto

**VidaFit** é uma landing page institucional para academia, desenvolvida para:

- Divulgar planos e serviços
- Atrair novos clientes
- Facilitar contato direto via WhatsApp e e-mail
- Permitir login de usuários
- Demonstrar organização profissional de front-end

Este projeto foi criado com foco em **portfólio, freelas e estudo**, aplicando boas práticas de estruturação, componentização e responsividade.

---

## 🚀 Tecnologias Utilizadas

- HTML5  
- CSS3 (arquitetura organizada)
- JavaScript  
- React  
- Google Fonts (Montserrat)

## ✨ Funcionalidades

- 🔐 Sistema de login

- 📲 Redirecionamento direto para WhatsApp  
- 📧 Redirecionamento direto para e-mail  
- 🎯 Estrutura otimizada para conversão
